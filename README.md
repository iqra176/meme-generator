# 😂 Meme Generator

A fun and interactive meme generator built with React. Choose a meme template, add your own text, and create a personalized meme.

## ✨ Features

* 🖼️ Choose from meme templates
* ✏️ Add custom text
* 🎨 Create personalized memes
* ⚡ Interactive React interface
* 📱 Responsive design
* 🔄 Generate new memes easily

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Vite
* Git & GitHub

## 🎨 How to Use

1. Choose a meme template.
2. Enter your desired text.
3. Customize the meme.
4. Generate your meme.
5. 🎉 Enjoy and share your creation!

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/iqra176/meme-generator.git
```

Go to the project folder:

```bash
cd meme-generator
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.
